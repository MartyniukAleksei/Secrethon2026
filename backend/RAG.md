# RAG для агента

Модель відповідей: налаштований GPT gateway. Ембедінги: окремий OpenAI API,
`text-embedding-3-large`, 1024 виміри. Індекс: pgvector у схемі `agent_knowledge`.
Таблиці пайплайна читаються без змін; тести та Alembic на production не запускаються.

## Railway

У Variables сервісу backend додайте:

```env
RAG_ENABLED=true
RAG_PROVIDER=openai
RAG_EMBEDDING_MODEL=text-embedding-3-large
RAG_DIMENSIONS=1024
EMBEDDING_BASE_URL=https://api.openai.com/v1
EMBEDDING_API_KEY=<ключ OpenAI API>
```

Ключ потрібен у backend, не у frontend. Docker-образ містить скрипт індексації.
Для першого запуску або оновлення даних, із каталогу backend (у контейнері `/app`):

```bash
python scripts/index_agent_knowledge.py          # лише оцінка змін
python scripts/index_agent_knowledge.py --apply  # створення індексу та ембедінги
```

Повторний запуск пропускає незмінені документи. Перерваний запуск можна продовжити:
вже збережені документи залишаються. Зміна моделі/розмірності потребує нового індексу.
Оновлення пайплайна індексуйте цим скриптом після публікації даних; автоматичного
розкладу для змін пайплайна немає.

Збережене користувачем дослідження індексується у фоні після запису в БД.
Схвалення лише для контексту чату не створює запис у БД/індексі. Якщо API недоступний,
дослідження залишається збереженим; повторіть CLI для відновлення індексу.

## Поведінка

Профіль конкретної компанії автоматично доповнюється релевантними уривками до
поточного питання. `search_knowledge` шукає за змістом у продукції, описах,
опублікованих фактах і схвалених дослідженнях. Ідентифікація компанії та статистика
залишаються точними запитами до БД. Для згаданої компанії пошук обмежено її ID.

Джерела зберігають походження й перевірку: `database_record`, `unverified`,
`user_verified`. Згода зберегти відповідь не перетворює її на перевірений факт.
Нецитовані висновки та змішані аналітичні секції не індексуються як докази.
Вебпошук через Tavily потребує окремої згоди, як раніше.

Для локального безплатного ембедера підтримано `RAG_PROVIDER=local`,
`RAG_EMBEDDING_MODEL=intfloat/multilingual-e5-small`, `RAG_DIMENSIONS=384`.
Потрібно завантажити модель; цей варіант використовує CPU/RAM сервера.
